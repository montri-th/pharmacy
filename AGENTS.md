# CityMETER Pharmacy — owner preferences

Set 2026-10-23 (release 0.1.0; 0.1.1 after the live walk the same day), carried over from CityMETER · Luxury Brands 0.5 and Restaurants 0.2.1 where the same contract applies.

- Apply current LDS 0.9.7 (v0.9.7-owner.1, standalone-0.9.7-r1) and preserve the map-first CityMETER layout. Colours come only from `assets/theme.css`, `js/scales.js` and `js/cues.js`; never approximate a value by eye. Analytical colours are the same HEX on both themes; EVID-05 map treatments use the `dataState` tokens (`--data-no-data`, `--data-zero-outline`).
- Read `PRODUCT_STATEMENT.md` before changing what the first screen argues. The question is “ร้านยาแน่นที่สุดอยู่ตรงไหน และเป็นร้านแบบไหน”.
- Counting unit is a contract (`js/model.js#unitWords`, `filterRows`): the default counts licensed rows only (one ขย1 licence = one premises; licence numbers are unique — `tests/data.test.js`). `count=all` counts every row and every word changes to “รายการ” (may repeat a storefront). Never mix the two units in one number, never call a row from another source a licensed pharmacy.
- Aha first, in 3D: the first paint is the `city` preset framing up to three densest แขวง/ตำบล (≥ 30 rows, rows per km² of the production area) of the LEADING province (the province of the densest eligible area), focused automatically (`auto`, no `areas` param). Show the combined density (Σrows ÷ Σkm²), the province benchmark (its rows ÷ its km²), the densest area outside that province, the unit and the eligibility rule, and the actions (ดูทุกพื้นที่, เปรียบเทียบพื้นที่) before filters. Small selections (< 1,000 rows) switch to a count Aha in the province holding the most placed rows. Snapshot numbers in the handoff JSON are fixtures, never UI constants.
- Metric choice is a contract: density (`density.area`, ร้าน/ตร.กม.) for แขวง/ตำบล and เขต/อำเภอ; totals (`count`) for province frames and matrix cells. Classes are geometric 1–2–5 (declared consumer classification, DATAVIZ-02) because pharmacy density spans four orders of magnitude. Never rank areas by density below the eligibility threshold.
- Membership is the code matched at build time from the row's own province/district/subdistrict names (`row.admin` says how: names · unique · point · district · province · none). Never re-assign by point-in-polygon on display coordinates or by store name at runtime. Rows placed only at district/province level are counted there and never painted into a subdistrict.
- National scale: `data/area-index.json` has every area without geometry (ranks, panels, charts and camera fits work at once); outlines load per province (`js/frames.js`) for the selection and for the provinces under the map at subdistrict zoom (≤ 6 per move). Never load all 77 frame files up front.
- EVID-05: the ขย1 register covers the whole country, so an area without a row is a measured zero (“0 ตามทะเบียน”, with the register date), never no_data; points are missing for most rows and are never invented — a row without a point still counts in its area.
- Focus + quiet context: detail (fills, coloured cue symbols, rounded focus massing) only for the focused part — the selected area, the district, the automatic or explicit focus. Everything else stays visible but quiet: outline-only areas, light label chips, grey context dots outside the tab order, quiet city massing. Below zoom 8 the province frames (count) carry the reading — except with a จังหวัด filter (province view, `js/map-layers.js` feature-state `province`): the province is fitted whole (no zoom floor) and its own แขวง/ตำบล are drawn from zoom 4, no province is count-filled, the legend is the density classes, and a click inside it opens the แขวง/ตำบล at any zoom.
- National scale adaptation (`js/app.js#mapFocusIds`, `syncMapFocus`): the AUTOMATIC focus quiets the map only while one of its areas is on screen; panned or zoomed elsewhere, every loaded frame is filled (the panel keeps the Aha). A user-chosen focus, a selected area or a district never releases. “ทั้งประเทศ” clears the จังหวัด filter and the focus (`?areas=all`) and fits the country.
- Pharmacy groups bind by stable id to LDS series with the series shape cue (`js/cues.js#GROUP_SERIES`; DATAVIZ-05); the quality list uses series 10 (plus). Never colour a category by hue alone; keep the cue in legends, lists, matrix headers and map symbols. No star cue (it would read as a rating).
- Chains are the 32 banners the sheet approved; rows that only resemble a chain show “ยังไม่ยืนยัน” and are not counted in it. Say “รายการอื่นของเครือนี้ในพื้นที่ — อาจเป็นร้านเดียวกัน”, never “สาขาเดียวกัน”. No logos were collected: do not add any without a registry (original bytes, sha256, role).
- Spatial join is display-time only (`js/building-join.js`): published points × focus-tier OSM footprints. Say “จุดตกในอาคาร”, never “ตั้งอยู่ใน”. It never changes a count. Map clicks, in order (`js/app.js#onMapClick`): focus pin → focus building (one point → store, several → building panel, none → falls through) → province frame (country zoom) → แขวง/ตำบล via `area-hit`. A click inside the selected area changes nothing; quiet context dots are never click targets.
- Breadcrumb is ประเทศไทย › จังหวัด › เขต/อำเภอ › แขวง/ตำบล with production codes and deep links `/v3/citymeter/{code}/D/{district}` · `/S/{subdistrict}` (production has no pharmacy dataset yet: no `?d=`). A store is the panel heading, never a crumb. A selection in another province moves the จังหวัด filter with it.
- Every panel view ends with dataset · source · date · boundary and what one counted unit is (`provenance()` in `js/panel.js`): the register date (28 พ.ค. 2569) and the check date (22 ต.ค. 2569). The licence status is not an opening check; the quality list has no validity dates — say so where they are shown.
- Basemap, massing and camera follow the Luxury Brands contracts (`js/map-style.js`, `js/massing.js`, `js/camera.js`): basemap tokens only, OSM heights are context, presets never move data, keep every 3D preset at pitch ≤ 90° − fov/2 − 3°. The first Aha frames three แขวง at about zoom 12.6, so the focus tier draws from zoom 12 in 3D when all its z14 tiles are loaded (`FOCUS_MIN_ZOOM`, ≤ `MAX_TILES` 16 nearest the camera); a truncated focus or plan view waits for zoom 13 (`CITY_MIN_ZOOM`).
- One symbol always represents one row with a published point; never cluster or aggregate. HTML pins from zoom 15.5 inside the focus only (≤ 320); quiet context dots are never focusable or clickable.
- Copy: short, natural Thai — ร้านยา / ร้าน / รายการ / เครือร้าน / ร้านยาคุณภาพ / แขวง·ตำบล / เขต·อำเภอ; units on every number (ร้าน, รายการ, ร้าน/ตร.กม.); a number and its unit never split across lines in running text (`js/panel.js#nw`). The closed top class prints like a density value (`js/scales.js#fmtTop`), never below the densest label.
- Charts: matrix cells are equal in size; the quality bar is a part-of-whole of the area's rows. No CSV download. No decorative brackets or coloured left rails. Visible focus everywhere.
- Privacy and publication: never copy phone numbers, addresses, map links, researcher notes or raw source records; source links are public https pages only. Never commit the internal research sheet, private Drive/Sheet URLs, credentials or the full LDS library. Review Thai at desktop and 390 px in light and dark before claiming done; local renders are not proof of a live release — run `npm run verify:live`.
- Releases bump one cache tag `?v=YYYYMMDD-rN` on every entry in `index.html` and, through the import map there, on every ES module (the frame files take the same tag from `import.meta.url`), together with `package.json` version, `design-intent.json` and the handoff JSON `productVersion` (`tests/release.test.js`). A new module must be added to the import map.
- MapLibre's CSS loads after `styles.css`: control and attribution rules are scoped under `.map-panel`; the phone legend and Aha card sit above `--attrib-height` (`js/app.js#trackAttribution`). The phone-portrait toolbar holds five buttons in one 330 px row; วิธีใช้ and the product statement live at the top of the sheet (`.sheet-links`, `#open-help-sheet`) — check `scrollWidth ≤ clientWidth` before adding a button. A camera fit jumps the map many times in one task: coalesce heavy work (labels, frame loading, massing re-shape) to after the last move (`scheduleLabelView`).
