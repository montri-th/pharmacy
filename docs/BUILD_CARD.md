# CityMETER Pharmacy — first useful value

Build Card ของสัญญาการใช้งานครั้งแรกของเดโมนี้ ใช้ LDS 0.9.7 release `v0.9.7-owner.1` เอกสาร standalone `lds-0.9.7-landometer-standalone-r1` SHA-256 `d3085cbc0a50195f1cbf0c77b1d77c0d19b84364daf2948eb367348d65432d96` ไม่ใช่ใบรับรองความสอดคล้องทั้งระบบหรือผลผ่านทุกเบราว์เซอร์

## First Aha — AHA-01

**ความเข้าใจแรกที่มีประโยชน์:** ร้านยาที่มีใบอนุญาตแน่นที่สุดในแขวง/ตำบลใด แน่นกว่าทั้งจังหวัดแค่ไหน และนอกจังหวัดนั้นแน่นที่สุดที่ไหน ผู้ใช้เริ่มสำรวจระดับพื้นที่ได้ทันทีโดยไม่ต้องเรียนรู้ตัวกรองก่อน

ข้อความเริ่มต้น (snapshot ชีต 22 ต.ค. 2569, ทะเบียน ณ 28 พ.ค. 2569): **“14.5 ร้าน/ตร.กม. — ร้านยาแน่นที่สุดใน 3 แขวงนี้”** ดินแดง · คลองเตยเหนือ · ลุมพินี — 145 ร้านใน 10 ตร.กม. · ทั้งกรุงเทพมหานคร **2.1 ร้าน/ตร.กม.** ข้อค้นพบรอง “นอกกรุงเทพมหานคร แน่นที่สุด: ตำบลหมากแข้ง อุดรธานี 11.7 ร้าน/ตร.กม.” และบอกหน่วยนับกับเกณฑ์ “นับร้านที่มีใบอนุญาต ขย1 ในทะเบียน อย. · จัดอันดับเฉพาะพื้นที่ที่มีอย่างน้อย 30 ร้าน” ตัวเลขทั้งหมดคำนวณจากข้อมูลทุกครั้ง ไม่ใช่ค่าคงที่ใน markup

แผนที่เปิดเป็นเมือง 3 มิติ (preset `city`) ที่โฟกัส 3 แขวงนั้นอัตโนมัติ (focus mode `auto`, URL ไม่มี `areas`): สี choropleth สัญลักษณ์ร้านตามประเภท (เฉพาะร้านที่แหล่งเผยแพร่พิกัด) และมวลอาคารมุมโค้งเฉพาะในโฟกัส ส่วนอื่นของเมืองเป็นบริบทที่เงียบ (กรอบเส้น ป้ายอ่อน จุดสีเทา มวลอาคารจาง) ขอบเขตของจังหวัดที่นำโหลดก่อน จังหวัดอื่นโหลดเมื่อจำเป็น

**One useful action:** “ดูทุกพื้นที่” (ยกโฟกัส, `?areas=all`) และ “เปรียบเทียบพื้นที่” (เปิดกราฟ) เมื่อโฟกัสปิดอยู่ ปุ่มกลายเป็น “โฟกัส 3 แขวงนี้” เมื่อเปลี่ยนตัวกรองหรือหน่วยนับ ข้อค้นพบ ตัวหาร และโฟกัสอัตโนมัติคำนวณใหม่ทั้งหมด

ข้อค้นพบเปิดในแผงอ่านก่อนตัวกรองใด ๆ (ตัวกรองพับอยู่ใน disclosure) บนจอแนวตั้งแคบ ข้อค้นพบและปุ่มเดียวกันแสดงในการ์ดบนแผนที่เหนือคำอธิบาย ขณะ bottom sheet ปิด ไม่มี onboarding modal ไม่มี decorative left rail หรือ bracket

## Evidence cue and calculation

แหล่ง: `data/pharmacies.json` (23,246 แถว; หน่วยเริ่มต้น 18,136 แถวที่มีใบอนุญาต) และ `data/area-index.json` (7,436 แขวง/ตำบล, `areaSqm` ของ production) การคำนวณ: `summarizeAreaInsight` (`js/area-insight.js`) บนแถวที่ผ่าน `filterRows`

| แขวง | รหัส | ร้าน | ตร.กม. |
|---|---|---:|---:|
| ดินแดง | `102601` | 75 | 4.48 |
| คลองเตยเหนือ | `103901` | 36 | 2.17 |
| ลุมพินี | `100704` | 34 | 3.36 |

รวม 145 ร้าน ÷ 10.01 ตร.กม. = 14.5 ร้าน/ตร.กม. (ไม่เฉลี่ยอัตราส่วน) ฐานเทียบ 3,232 ร้าน ÷ 1,571.4 ตร.กม. ของกรุงเทพมหานคร = 2.06 ความเป็นสมาชิกพื้นที่คือรหัสที่จับคู่จากชื่อพื้นที่ของแถว ตัวเลขเป็นสัดส่วนเชิงพรรณนาภายในทะเบียนนี้ ไม่ใช่ความครบของตลาด ยอดขาย หรือการเข้าถึงต่อประชากร

API ของฟังก์ชัน: `{mode, minRows, areas, areaIds, home, count, km2, density, homeRows, homeKm2, baselineDensity, ratio, share, totalRows, placedRows, areaCount, eligibleCount, outside}` และ `filterAreaRows(rows, set)` คืนแถวเดิมตามลำดับเดิม ไม่แตะพิกัด

ถ้าตัวกรองไม่มีร้าน แสดง empty state “ไม่พบร้านตามตัวกรองนี้” พร้อม “นับทุกรายการ” (ในหน่วยใบอนุญาต — บางเครือไม่มีชื่อเครือในทะเบียน) และ “ล้างตัวกรอง” ห้ามแปลงศูนย์เป็น “ไม่มีร้านยาที่นี่”

## Prerequisites and safe paths — AHA-01-A

- **จำเป็นสำหรับข้อค้นพบ:** `data/pharmacies.json`, `data/area-index.json` โหลดและ parse ได้บน HTTP(S) เปิดเป็นไฟล์ในเครื่องจะถูกพาไปเว็บสาธารณะ (`js/launch.js`)
- **ไม่จำเป็น:** บัญชี ข้อมูลส่วนตัว ตำแหน่งผู้ใช้ สิทธิ์อุปกรณ์ การแชร์ ไลบรารีกราฟ WebGL tiles แผนที่ ขอบเขตรายจังหวัด หรืออาคาร
- แผนที่ (MapLibre จาก unpkg + tiles OpenFreeMap) และขอบเขตรายจังหวัดโหลดแยก ถ้าล้มเหลว ข้อค้นพบ แผง กราฟ และตารางยังใช้ได้ และมีปุ่มลองโหลดแผนที่ใหม่; จังหวัดที่โหลดขอบเขตไม่สำเร็จลองใหม่เมื่อเลือกครั้งถัดไป
- ข้อมูลหลักโหลดไม่ได้ → หน้าแสดงสถานะ error พร้อม retry และลิงก์เว็บสาธารณะ ไม่แสดงตัวเลขว่าง
