# Product Brief — CityMETER · Pharmacy 0.1

คู่กับ `product-brief.json` (schema 1.5.0) แก้คู่กันเสมอ ป้ายหลักฐานตาม MBB §3.7 ตัวเลขเป็น snapshot ชีต 22 ต.ค. 2569 (ทะเบียน ขย1 ข้อมูล ณ 28 พ.ค. 2569) และเป็น regression fixture ไม่ใช่ค่าคงที่ใน UI

## 1. งานของผลิตภัณฑ์

คัดและเทียบแขวง/ตำบลทั่วประเทศด้วยความหนาแน่นของร้านยาที่มีใบอนุญาต ประเภทร้าน เครือร้าน และร้านยาคุณภาพ ก่อนตัดสินใจเรื่องทำเลหรือเขตการขาย นับใบอนุญาตละครั้ง และบอก dataset · source · date · boundary ของทุกตัวเลข

คำถามของหน้าแรก: **“ร้านยาแน่นที่สุดอยู่ตรงไหน และเป็นร้านแบบไหน”** ผู้ใช้ (Hypothesis): ทีมขยายสาขาของเครือร้านยาและร้านสุขภาพ/ความงาม · ทีมขายและวางเขตของผู้ผลิต/ผู้จัดจำหน่ายยาและเวชภัณฑ์ · นักวิเคราะห์ ที่ปรึกษา และหน่วยงานท้องถิ่น

เส้นทาง: ข้อค้นพบแรก 3 มิติ → แขวง/ตำบล → เขต/อำเภอ → ร้าน → อาคารที่จุดของร้านตก → แขวง/ตำบลข้าง ๆ → กราฟและตาราง → ทั้งประเทศ → พื้นที่เดียวกันใน production

## 2. สิ่งที่เปลี่ยนจากฐาน Restaurants 0.2.1 / Luxury Brands 0.5

กล้อง basemap มวลอาคาร pictogram breadcrumb และ handoff ใช้สัญญาเดิม สิ่งใหม่:

- **ระดับประเทศ:** ดัชนีพื้นที่ 7,436 แขวง/ตำบลแบบไม่มีเรขาคณิต + ขอบเขตรายจังหวัดที่โหลดเมื่อจำเป็น (`framesContract`)
- **หน่วยนับ:** ร้านที่มีใบอนุญาต ขย1 เป็นค่าเริ่มต้น ทุกรายการเป็นหน่วยแยกที่ใช้คำว่า “รายการ” (`countingUnitContract`)
- **ความเป็นสมาชิก:** จับคู่ชื่อจังหวัด/อำเภอ/ตำบลของแถวกับรหัส production ตอน build และบันทึกวิธีในทุกแถว (`row.admin`)
- **ข้อค้นพบแรก:** 3 พื้นที่ของจังหวัดที่นำ (หนึ่งฉาก 3 มิติ) เทียบทั้งจังหวัด และบอกพื้นที่ที่แน่นที่สุดนอกจังหวัดนั้น
- **ระดับสีเรขาคณิต 1–2–5** สำหรับความหนาแน่นและยอดรวม (ความหนาแน่นต่างกันสี่หลัก)
- **0 ตามทะเบียน** แทน no_data (ทะเบียนครอบคลุมทั้งประเทศ); พิกัดมีเพียง 17% ของแถว — พื้นที่ไม่พึ่งหมุด
- ไม่มีสถานที่ โลโก้ หรือ venue x-ray (รอบวิจัยนี้ไม่ได้เก็บ)

**รุ่น 0.1.1 (เดินตรวจเว็บจริงด้วย Chrome ของเจ้าของ 23 ต.ค. 2569):** ภาพแรกมีมวลอาคาร 3 มิติในโฟกัส (กล้องอยู่ที่ซูม 12.6 ซึ่ง 0.1.0 ยังไม่วาดอาคาร) · เลือกจังหวัดแล้วเห็นทั้งจังหวัดพร้อมสีรายแขวง/ตำบล · ขอบบนของระดับสีสูงสุดไม่ต่ำกว่าป้ายของพื้นที่ที่แน่นที่สุด · แถบเครื่องมือบนมือถือพอดีหนึ่งแถว · ตัวเลขกับหน่วยไม่แยกบรรทัด · ข้อความใต้แผนที่บอกว่าจุดเทาเป็นจุดนอกโฟกัสทั้งหมด ไม่ใช่เฉพาะในจอ — รายละเอียดใน VERIFICATION.md

## 3. ขอบเขตข้อมูลสามชั้น (row scopes)

| scope | นิยาม | ผู้ใช้ |

## 4. First Aha

พื้นที่ที่มีอย่างน้อย 30 แถว เรียงตามความหนาแน่น → พื้นที่อันดับ 1 กำหนดจังหวัดที่นำ → สูงสุด 3 พื้นที่อันดับต้นของจังหวัดนั้น · Σแถว ÷ Σตร.กม. · ฐานเทียบ = แถวของจังหวัดนั้น ÷ ตร.กม. ของจังหวัด · ข้อค้นพบรอง = พื้นที่ที่แน่นที่สุดนอกจังหวัด · ต่ำกว่า 1,000 แถวเปลี่ยนเป็นข้อค้นพบแบบจำนวนในจังหวัดที่มีแถว (ที่ระบุตำบลได้) มากที่สุด

ค่าเริ่มต้น: **14.5 ร้าน/ตร.กม.** ดินแดง (75) · คลองเตยเหนือ (36) · ลุมพินี (34) = 145 ร้านใน 10.01 ตร.กม. · ทั้งกรุงเทพมหานคร 2.06 (3,232 ร้าน ÷ 1,571.4 ตร.กม.) · นอกกรุงเทพฯ ตำบลหมากแข้ง อุดรธานี 11.7 (122 ร้าน) — หน่วยทุกรายการ: สุริยวงศ์ · ถนนพญาไท · สีลม 30.2 รายการ/ตร.กม.

## 8. ขอบเขตรายจังหวัด

ดัชนี (`data/area-index.json`) ทำให้อันดับ แผง กราฟ และการตั้งกล้องทำงานทันที ขอบเขต `data/frames/{CODE}.json` โหลดเมื่อ: จังหวัดของการเลือก (ตัวกรอง พื้นที่ อำเภอ โฟกัส ร้าน) และหลังขยับกล้องที่ซูม ≥ 7.5 จังหวัดใต้แผนที่สูงสุด 6 จังหวัดใกล้กลางจอ (concurrency 2, tag ตามรุ่น) โหลดไม่สำเร็จไม่จำ และลองใหม่เมื่อเลือกครั้งถัดไป

## 9. กล้อง basemap มวลอาคาร

ตาม `cameraContract`, `basemapContract`, `massingContract` (สืบจาก Luxury Brands/Restaurants): preset plan/city/model, fitPitched บนจุดของขอบเขต (หรือมุมกรอบจากดัชนีก่อนขอบเขตมาถึง), จังหวัดที่เลือกจัดกล้องให้เห็นทั้งจังหวัด (ไม่มีซูมขั้นต่ำ; สีตำบลของจังหวัดนั้นแสดงตั้งแต่ซูม 4), ทั้งประเทศ plan ซูม ≤ 7, basemap paper บน OpenFreeMap, มวลอาคารเมืองเงียบ (ซูม ≥ 13) + โฟกัสโค้ง (3 มิติจากซูม 12 เมื่อไทล์ของโฟกัสครบ ≤ 16 ไทล์ที่ใกล้กล้อง มิฉะนั้นจากซูม 13) อาคารที่เปิดอยู่ใช้ชั้นสีข้อมูลของ massing
